# AsyncFounders Agent Contract

Read the installed `$build-asynfounders` skill before broad product work. If it is unavailable, preserve these invariants:

- Build a versioned team-state ledger, not a transcript archive.
- Keep `fact`, `idea`, `assumption`, `decision`, `question`, `task`, and `conflict` distinct.
- Preserve author, time, evidence, confidence, audience, lifecycle state, and acknowledgement.
- Never overwrite disagreement or silently promote a proposal into a decision.
- Compile briefings from relevant unseen deltas and record unknown answers instead of inventing them.
- Keep CALL-E server-side, callback-first, explicitly approved, payload-idempotent, masked, and dry-run by default.
- Keep demo mode fully usable without credentials or external side effects.
- Preserve Supabase row-level isolation. Never query company data without an authenticated membership boundary.
- Store public Supabase configuration client-side; keep the service-role key and CALL-E key server-only.
- A teammate's full phone number must never be returned to another browser client.
- Validate mobile, keyboard, reduced-motion, malformed results, duplicate calls, and conflict resolution before handoff.

The product voice is direct, human, and operational. Avoid generic CRM language, decorative metrics, transcript dumps, and fake automation claims.
